# Pomodoro-Timer
番茄时钟是一款为"自己用、简洁、稳定、可靠"而生的计时工具。它没有花哨界面，不联网、不收集任何隐私、没有任何广告，启动即用。最大的特点是**体积只有 28 KB**,对老机型、低存储设备极其友好。Pomodoro Timer is a no-nonsense focus tool built to be simple, stable and reliable. No fancy UI, no network access, no privacy collection, no ads — just open and use. Its headline feature is the **28 KB ** , perfect for old devices and tight storage.
